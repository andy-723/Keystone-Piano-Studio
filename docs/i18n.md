# Languages (English, 中文, Tiếng Việt)

One language switch (EN / 中文 / VI) covers the public site and the signed-in app. The choice is
saved in the browser (`keystone.siteLang`) and, in the family portal, defaults to the guardian's
preferred language.

## How it works

- Components keep English text. Nothing else changes in a component when a language is added.
- `useSiteTranslation()` is mounted once at the app root. After the page loads it walks the page
  and swaps English text, `aria-label`, `title`, `alt` and `placeholder` for the chosen language,
  and keeps doing so as React updates the page (a MutationObserver). Switching back to EN puts
  the original English back.
- Lookup order (`uiText` in `src/i18n/marketing/site-lang.ts`):
  1. marketing dictionaries `src/i18n/marketing/zh-CN.ts`, `vi.ts`
  2. app dictionaries `src/i18n/app/*.ts` (`"English": ["中文", "Tiếng Việt"]`)
  3. the setup-wizard dictionary `src/i18n/setup-wizard.ts`
  4. en-AU dates and times (`appDate`): "Mon 16 Nov" becomes 11月16日 周一 / T2, 16 thg 11
  5. patterns: a key like `"Lessons in Term {term}"` matches "Lessons in Term 2". Placeholders
     named `n`, `count`, `total`, `term`, `days`, `hours`, `weeks`, `year`, `seen`, `stage`,
     `minutes`, `pct` only match numbers. Captured values are translated too when known.
  6. text joined with " · " is translated piece by piece.
- React often splits `Lessons in Term {term}` into two text nodes. When an element contains only
  text, the translator joins it first so word order can change.

## Adding copy

Add the English string and both translations to the right file in `src/i18n/app/`. Use the exact
text React renders (straight apostrophes for `&apos;`). `src/test/app-i18n.test.tsx` checks that
every pattern still matches in both languages.

## Never translated

- Anything people write: chat messages, news titles and bodies, client notes, shared and lesson
  notes, assignment tasks and bodies, review comments, Library item text, group descriptions and
  Tax Lite session notes. These carry `data-no-translate`; add it to any new element that shows
  text a person typed.
- Textareas and typed input values.
- Studio agreement clause wording and the agreement preview (legal text; needs a lawyer-reviewed
  translation, not a machine one). Labels and buttons around it are translated.
- Consent statements on the family terms screens in Vietnamese (they have reviewed 中文 already).
- The reviewed tax wording in `src/lib/tax-copy.ts` (GST threshold, ATO rates, super, Stripe fees).
- Studio help articles in `src/lib/help/articles.ts` (family articles already have 中文).
- The Keystone admin console (`/admin`), which only Keystone staff use.
- Mock/demo data such as student names and sample messages.
