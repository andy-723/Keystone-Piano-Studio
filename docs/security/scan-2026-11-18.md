# Security scan triage, 18 Nov 2026

Source: purpleteam report for www.keystonemusichq.com and this repo at commit 679154b
(136 findings: 15 High, 51 Medium, 5 Low, 65 Info). Each finding was checked against the code
and the full git history (427 commits) on 18 Nov 2026.

## Result

No real secret is or ever was committed. Nothing needs rotating because of this scan.
Fixes for the real (lower severity) items are in the PR that added this file.

## High: hard-coded credentials (1-15) - false positives

| # | Where | Why it is not a secret |
|---|---|---|
| 1-5 | `.env.example` | Every key is empty (`RESEND_API_KEY=`). The scanner read the next line's variable name as the value. `git log -p -- .env.example` shows no value was ever filled in. |
| 6 | `SupportRequestForm.tsx` `accessToken` | Variable holding the signed-in user's session token at runtime. |
| 7 | `carousel.tsx` `onKeyDownCapture` | A React event handler prop. |
| 8-10, 15 | `onToken`, `startToken` | Turnstile callback props (`{setCaptcha}` etc.). |
| 11-12 | migrations 0003, 0010 `refresh_token_secret_id` | Column holding a Supabase Vault id, not the token. Tokens live encrypted in Vault. |
| 13-14 | `siteKey` | Turnstile site key prop. Site keys are public by design. |

History sweep: searched every commit for Resend (`re_`), Stripe (`sk_`, `rk_`, `whsec_`), Supabase
JWTs (`eyJ...`), `sb_secret_`, Google client secrets (`GOCSPX-`), Turnstile secrets (`0x4AAAA`),
AWS keys and private key blocks. No matches. No `.env` file other than `.env.example` was ever committed.

## Medium

| # | Finding | Verdict |
|---|---|---|
| 16-60 | "Database dump committed" for `supabase/migrations`, `rollbacks`, `tests`, `seed.sql`, `scripts/inventory-real-data.sql` | False positive. These are schema, rollback and test SQL that belong in git. No row data or credentials. |
| 61 | `execSync` in `scripts/check-migrations.mjs` | Real but CI-only (input is the PR's target branch). Fixed: `execFileSync` with an argument array. |
| 62-66 | "Undocumented" `/contact`, `/demo`, `/help`, `/login`, `/_serverFn/{id}` | False positive. All are TanStack file routes in `src/routes/`; `/_serverFn` is how TanStack Start calls server functions. |

Follow-up from 62 (server functions are public endpoints): every `createServerFn` was reviewed.
All live paths verify the Supabase session (`verifyAccessToken`) and `requireStudioRole` /
`requirePlatformAdmin`, or a hashed invite token / Turnstile for the public family join and help
forms. Two old invite functions (`createInvitationFn`, `resendInvitationFn`) still accepted an
`actorUserId` from the browser. On the live site that path was already refused by the MFA check
(`assertStaffAal` needs `aal2` from a verified token), so it was not exploitable, but it now
refuses outright outside the mock backend. The unused `runInviteRemindersFn` (mock data only, no
auth) was removed; the real job is `/api/cron/invite-reminders`.

## Info (72-136)

Duplicate code, unused shadcn UI files and a few unused helpers: code tidiness, not security.
Optional clean-up later. #136 (Turnstile and Google Fonts load from third parties): expected. Turnstile is listed in the
privacy policy's service provider table; Google Fonts is not (it sees each visitor's IP address).
Either self-host the fonts or add Google Fonts to that table at the next legal update. A full
Content-Security-Policy is a later step.

## Also added (not in the report)

- Security headers on every response through Nitro `routeRules` in `vite.config.ts`:
  `Content-Security-Policy: frame-ancestors 'none'; base-uri 'self'; object-src 'none'`,
  `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`,
  `Referrer-Policy: strict-origin-when-cross-origin`, `Strict-Transport-Security`.
- Cron routes compare `CRON_SECRET` in constant time (`src/server/cron-auth.ts`).

## Not changed, noted

- `/api/terms/pdf` renders a PDF from posted text without sign-in (size capped at 512 KiB). Used
  before families sign in. Low risk; could add Turnstile or rate limiting later.
- The scanner needs tuning: treat `.env.example`, `supabase/migrations`, generated
  `routeTree.gen.ts` and props named `*Token`/`siteKey` as non-findings.
